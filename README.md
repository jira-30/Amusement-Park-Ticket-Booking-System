
The Amusement Park Ticket Booking System is a database-driven application that manages rides, customers, ticket types, and
bookings through a structured relational model. The planned use case involves customers selecting rides and ticket types,
entering their details, and creating bookings, while administrators manage ride information and view analytics. The MySQL
data store paradigm provides a strictly defined schema with enforced relationships, ensuring transactional integrity, accurate
capacity tracking, and reliable analytics. CRUD operations are handled via the Node.js/Express backend, with SQL queries
performing data validation, joins, and aggregation for reporting
